# Task 12 — Fornecedores Pages (Frontend)

## Objetivo
Telas CRUD de fornecedores no painel do comprador.

## Páginas
- **`/suppliers`**: Listagem com busca, filtro por categoria, paginação
- **`/suppliers/new`** e **`/suppliers/:id/edit`**: Formulário com: nome, CNPJ/CPF, contato, email, telefone, categorias atendidas (multi-select)

## Componentes
- Multi-select de categorias (chips com X para remover)
- Máscara de CNPJ/CPF e telefone

## Critérios de Aceite
- [ ] CRUD completo funciona
- [ ] Multi-select de categorias funciona
- [ ] Máscaras de input aplicadas
- [ ] Mensagem de limite do plano quando 403
